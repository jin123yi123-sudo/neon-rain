# 霓雨街区 / NEON RAIN

赛博朋克横版射击小游戏。原生 Canvas、程序化像素美术，无运行时依赖。HD-2D 风格视觉模拟：建筑侧面与屋檐、视差远景、模糊前景车辆、雨幕、霓虹灯和地面反光；不是完整 3D 引擎。

## 运行

需要 Node.js 20.11+，在项目目录运行 `node server.mjs`，打开 http://localhost:4173 。也可将目录作为静态站点部署（需要 HTTP 服务，不支持直接双击 HTML）。运行测试：`node --test`。

## 操作

- A/D 或左右方向键移动；空格跳跃；W/S 或上下方向键攀爬橙色外梯。
- 鼠标瞄准，按住左键 360° 射击；J + 方向键八向射击。
- ESC 暂停；失败后 R 重试。以桌面键鼠为主要操作方式。
- 击败每章最右侧重装守卫后，前往发光撤离信标即可通关，不要求全灭。

三个区域：雨巷夜市、地下暗流、天际防线。含章节像素肖像和可跳过的文字剧情、街道兵、地下兵、楼内枪手、无人机、重装守卫，以及医疗、护盾、散射、速射掉落。

## 存档与分享

本地存档保存在浏览器 localStorage，记录章节、解锁进度、累计分数；继续时从区域起点恢复，战场即时状态不保存。通关自动保存，也可手动保存。分享链接的 URL hash 包含存档，不需要账户或服务器数据库。操作指南可导入完整链接或 Base64 存档码。对方必须能访问同一部署地址，localhost 链接不能直接跨设备访问。存档属于休闲游戏进度，可编辑，不用于竞技排行。

## 技术与美术

所有场景和角色由代码绘制，未使用第三方游戏素材。页面字体使用 Google Fonts，加载失败会回退系统字体。声音由 Web Audio 合成，默认关闭。未实现多人联机、云端账户、移动端触控操作。

## 静态发布

仓库包含 GitHub Pages 工作流。仓库 Settings → Pages 中将 Source 设为 GitHub Actions 后可自动发布。私有仓库 Pages 是否可用取决于账户计划；本地运行不受影响。
