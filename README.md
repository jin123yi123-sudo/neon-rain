# 霓雨街区 / NEON RAIN

赛博朋克横版射击游戏，三个区域与短篇图文剧情。原生 Canvas，无运行时依赖。正式场景、角色、敌人、道具、车辆、梯子与平台均为生成式位图美术。HD-2D 风格由有立体质感的建筑图像、像素精灵、视差合成、前景虚化与实时雨幕构成，游戏本身使用 2D 碰撞。

[在线试玩](https://jin123yi123-sudo.github.io/neon-rain/)

## 运行

需要 Node.js 20.11+，在项目目录运行 `node server.mjs`，打开 http://localhost:4173 。也可将目录作为静态站点部署（需要 HTTP 服务，不支持直接双击 HTML）。运行测试：`node --test`。

## 操作

手机会自动使用横屏触控布局，也可使用[手机专用入口](https://jin123yi123-sudo.github.io/neon-rain/?mode=mobile)。左杆移动/攀梯，右杆瞄准射击，独立跳跃、冲刺及趴下按钮。电脑版保留原操作。平台接入说明见 `MOBILE.md`。

- A/D 或左右方向键移动；空格跳跃；W/S 或上下方向键攀爬橙色外梯。
- 鼠标瞄准，按住左键 360° 射击；J + 方向键八向射击。
- ESC 暂停；失败后 R 重试。以桌面键鼠为主要操作方式。
- SHIFT 短距冲刺；S + 空格从平台下落；空格按住时间控制跳跃高度。
- 顶栏可进入全屏。进入章节后自动将游戏区域滚到屏幕中间。
- C 按住趴下/匍匐，降低受击高度；深水中 W 上浮。
- 封锁战须清除本区敌人才能继续；击败每章独有 Boss 后前往撤离信标。

三个区域：雨巷夜市、地下暗流、天际防线。含统一人物设定的剧情插画与可跳过对白、街道兵、地下兵、楼内枪手、无人机、重装守卫，以及医疗、护盾、散射、速射掉落。

## 战场机制

- 高压伤害仅发生在标记的带电地面，可跳过；地下蒸汽口周期喷发。
- 井盖伏兵靠近后钻出，露出前无法受击；雨棚、檐口和屋顶组成连续跳跃路线。
- 地下深水没过头部后开始缺氧伤害；离水恢复本次溺水损失的一半，最多 8 HP，不可反复刷血。
- 可破坏货箱、固定路障和低矮管道提供掩体与匍匐路线。盾兵正面防御、冲锋兵近战、投弹兵抛射、狙击手预瞄、炮台连射形成组合。
- 三关 Boss 分别为赤犬镇压车、渊井高压泵蛛和天幕炮艇，各有攻击模式与半血强化阶段；泵蛛在核心开启时受到更多伤害。

操作采用 120Hz 固定步长物理、离地 120ms 起跳容错、140ms 跳跃输入缓冲、梯子吸附与停留、平滑镜头、拾取吸附。角色使用站立、六帧交替迈步跑动与跳跃图集组合。跑步周期按移动距离推进，每 108 像素完成一次左右脚循环，倒退射击时反向播放。

## 存档与分享

本地存档保存在浏览器 localStorage，记录章节、解锁进度、累计分数；继续时从区域起点恢复，战场即时状态不保存。通关自动保存，也可手动保存。分享链接的 URL hash 包含存档，不需要账户或服务器数据库。操作指南可导入完整链接或 Base64 存档码。对方必须能访问同一部署地址，localhost 链接不能直接跨设备访问。存档属于休闲游戏进度，可编辑，不用于竞技排行。

## 技术与美术

正式素材通过内置 ImageGen 生成，保存在 `assets/`。美术规范见 `ART-DIRECTION.md`，提示词见 `assets/prompts.json`。图集保留透明通道，按单个素材实际边界裁切，代码仅负责场景合成及实时特效。页面字体使用 Google Fonts，加载失败回退系统字体。声音由 Web Audio 合成，默认关闭。未实现多人联机、云端账户和小红书原生客户端接入。
